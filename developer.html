Technology Stack

Frontend

Pure HTML, CSS, and JavaScript — no frameworks, optimized for speed and mobile responsiveness.

Backend

Node.js with Express.js — lightweight, high-performance REST API with secure authentication.

Database

MongoDB with Mongoose — flexible document-based storage for all platform data.

AI Integration

Custom AI chat system for intelligent tutoring, explanations, and study assistance.

Hosting

Reliable cloud hosting with auto-deployment and global CDN for fast loading.

Security

JWT authentication, password hashing, rate limiting, and secure payment processing.

Build Philosophy

🚀 Student-First Design: Every feature is built with OAU students in mind — from exam simulation to AI tutoring.

📱 Mobile-First: The platform is optimized for mobile devices, because most students access it on their phones.

🔒 Privacy & Security: All user data is encrypted and protected. We never share your information with third parties.

💡 Continuous Improvement: Regular updates based on student feedback and changing academic needs.
