Technology Stack

Frontend

HTML5, CSS3, Vanilla JavaScript — no frameworks, no dependencies, pure performance. Responsive design works on all devices from 320px to 4K screens.

Backend

Node.js with Express.js — lightweight, high-performance REST API server. JWT authentication, rate limiting, helmet security, CORS protection.

Database

MongoDB with Mongoose ODM — flexible document-based storage for questions, users, scores, courses, materials, chats, notifications, and admin data.

AI Integration

Custom AI chat system for intelligent tutoring. Provides instant explanations, study tips, and answers. Built with natural language processing capabilities.

Hosting & Deployment

Render (backend API) and Vercel (frontend) — reliable cloud hosting with auto-deployment from GitHub. Global CDN for fast loading worldwide.

Security

Password hashing (bcryptjs), JWT tokens, helmet security headers, CORS, rate limiting, input validation, XSS protection, and secure payment processing.

Payment System

Secure payment gateway integration supporting multiple plans (Free, Semester ₦2,000, Full Session ₦3,500). Instant activation upon successful payment.

Email System

Nodemailer integration for admin approval emails, notifications, and password recovery. Gmail SMTP with app-specific passwords.

Data Architecture

The platform uses 8 MongoDB collections (models):

  • Users — Student accounts with scores, achievements, streaks, preferences, study goals, and referral data
  • Courses — Course listings with themes (gradients, icons), test/exam settings (timers, question counts), multi-faculty support
  • Questions — 45,000+ questions with modes (exam/test), options, hints, explanations, difficulty levels
  • Admins — Approved administrator accounts with roles, performance tracking, contribution metrics
  • AdminApplications — Pending/reviewed admin applications with quiz scores, profile data, IP tracking
  • Notifications — User notifications with read status, types (info/success/warning), global broadcast support
  • Chats — User-to-admin messaging system with CEO broadcast, reply threading, status tracking
  • CourseMaterials — Uploaded slides, past questions, textbooks, YouTube links with faculty/level/semester filtering
  • Scores — Exam and test results with percentages, time tracking, course breakdowns

API Architecture

The backend exposes REST API endpoints at https://oau-exam-api.onrender.com/api

Authentication

POST/api/auth/register
Create new student account with faculty, department, level, security question
POST/api/auth/login
Authenticate with username/password, returns JWT token
GET/api/auth/me
Get current user profile with scores, achievements, preferences

Admin & CEO

POST/api/admin-auth/admin-login
Admin login with email + password verification
POST/api/admin-auth/verify-ceo
CEO password verification against environment variable
GET/api/admin-auth/applications
CEO: View all pending/approved/rejected admin applications
PUT/api/admin-auth/applications/:id
CEO: Approve or reject admin application, auto-creates admin account

Questions & Courses

GET/api/admin/questions/:courseCode/:mode
Get questions for exam/test mode (public, no auth required)
POST/api/admin/questions/bulk
Bulk add questions in JSON format with validation
GET/api/admin/courses
Get all courses with question counts and settings
POST/api/admin/courses
Add or update course with theme, test/exam settings, faculties

Notifications & Chat

POST/api/admin/notifications/global
Send notification to all registered users
POST/api/admin/notifications/private
Send private notification to specific user
POST/api/chat/ceo-send
CEO sends message to specific admin
